# ХУЯНКИ

Карточки с интервальным повторением. Без аккаунтов, без синка, без ада настроек Anki.

**https://realfactchecknews-eng.github.io/huyanki/**

- Алгоритм **FSRS-4.5** (модель памяти: стабильность / сложность / извлекаемость) — карточка приходит ровно тогда, когда вероятность вспомнить падает до целевой (по умолчанию 90%).
- Учёт **в обе стороны**: лицо→оборот и оборот→лицо — независимые следы памяти со своими интервалами.
- **Interleaving** — темы и направления перемешиваются, сильно просроченное идёт вперёд.
- Забыл → карточка возвращается в конце этой же сессии.
- Прогресс в localStorage, бэкап в JSON.

**Библиотека** (иконка 📚), 630 карточек:

| Колода | Карточек | Формат |
|---|---|---|
| 🇬🇧 Английский B1+ → C1 | 219 | слово ↔ перевод, обе стороны |
| ⚖️ Право РФ | 153 | вопрос → ответ, в подсказке статья |
| 🌐 Обществознание | 139 | вопрос → ответ, в подсказке раздел |
| 🎖️ Вторая мировая война | 119 | дата ↔ событие, обе стороны |

Карточки по праву и обществознанию сформулированы **как вопросы**, а не как определения («Назови признаки правового государства», а не «Правовое государство — это…»), длинные определения разбиты на атомарные. Такие колоды учатся только в одну сторону — обратный ход у вопроса бессмысленен.

«Добавить новые» доливает недостающие карточки, «Заменить» пересобирает колоду по свежей версии пака: прогресс по совпадающим карточкам сохраняется, устаревшие удаляются.

Колоды правятся карандашом на плитке. Формат строки: `вопрос | ответ | подсказка`

Клавиши: `Space` — показать/«Норм», `1..4` — оценка, `Esc` — выход.
