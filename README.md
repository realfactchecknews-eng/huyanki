# ХУЯНКИ

Карточки с интервальным повторением. Без аккаунтов, без синка, без ада настроек Anki.

**https://realfactchecknews-eng.github.io/huyanki/**

- Алгоритм **FSRS-4.5** (модель памяти: стабильность / сложность / извлекаемость) — карточка приходит ровно тогда, когда вероятность вспомнить падает до целевой (по умолчанию 90%).
- Учёт **в обе стороны**: лицо→оборот и оборот→лицо — независимые следы памяти со своими интервалами.
- **Interleaving** — темы и направления перемешиваются, сильно просроченное идёт вперёд.
- Забыл → карточка возвращается в конце этой же сессии.
- Прогресс в localStorage, бэкап в JSON.

**Библиотека** (иконка 📚): готовые крупные колоды — английский B1+→C1 (157), право РФ (116), Вторая мировая (119). Повторное нажатие «Обновить» доливает только новые карточки, прогресс не трогает.

Колоды правятся карандашом на плитке. Формат строки: `вопрос | ответ | подсказка`

Клавиши: `Space` — показать/«Норм», `1..4` — оценка, `Esc` — выход.
